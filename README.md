# Bayesian Models for Cost-Effectiveness Analysis of an SCD Risk Model in Hypertrophic Cardiomyopathy (HCM)

This repository contains code and (processed) data to perform a probabilistic cost-effectiveness (CE) analysis of a prognostic model for sudden cardiac death (SCD) in patients with hypertrophic cardiomyopathy (HCM). The analysis combines Bayesian posterior samples (fitted in WinBUGS/OpenBUGS) with a cohort Markov model to estimate costs, quality-adjusted life years (QALYs), and incremental cost-effectiveness across risk groups.

## Background

Hypertrophic cardiomyopathy (HCM) is a leading cause of sudden cardiac death (SCD) in younger adults. Clinical risk algorithms such as the HCM Risk-SCD model provide estimates of SCD risk but do not fully propagate parameter uncertainty into economic evaluations. This project demonstrates a fully probabilistic approach, using Bayesian posterior samples to reflect uncertainty in predictions when estimating cost-effectiveness of clinical decision strategies.

## Aim

To perform a cost-effectiveness analysis for a prognostic SCD risk prediction model and compare management strategies across risk groups while propagating uncertainty from model parameters to health and cost outcomes. For clinical background, see: C O'Mahony (2014) "A novel clinical risk prediction model for sudden cardiac death in hypertrophic cardiomyopathy (HCM risk-SCD)." Eur Heart J. 2014;35(30):2010-20. https://pubmed.ncbi.nlm.nih.gov/24126876/

## Data

Individual-level HCM patient variables used in this project. The `prep_study_data.R` script expects raw data (not included here) and writes cleaned/imputed files into the `data/` directory.

| syncope | Syncope (binary) |

Note: This repository does not contain identifiable patient-level raw data. If you have access to the original dataset, run `prep_study_data.R` locally to generate the analysis files.


## Model overview

The analysis has two components:

1. Bayesian model (WinBUGS/OpenBUGS) fitted to individual-level data to obtain posterior distributions for model parameters and event probabilities.
2. A cohort Markov model using posterior samples as inputs to simulate long-term costs and QALYs for alternative management strategies. The first-stage decision-tree determines initial management; the Markov model captures long-term transitions and outcomes.

## Quick start

1. Clone the repository and open it in R or RStudio.

2. Prepare data:
   - From R: source("prep_study_data.R")
   - Or: Rscript prep_study_data.R
   This creates analysis-ready files in `data/`.

3. Fit the Bayesian model (requires WinBUGS/OpenBUGS and an R interface such as R2WinBUGS or BRugs):
   - Open `BUGS/script.R` and run the script to call WinBUGS and save posterior samples.

4. Run the cost-effectiveness simulation:
   - From R: source("main-ce-analysis.R")
   - Or: Rscript main-ce-analysis.R

5. Generate figures and tables:
   - Run `pop_counts_plot.R` and other helper scripts to create plots in `output/`.


## Dependencies

Key software and R packages used in the analysis (not a complete list):

- R (>= 3.6 recommended)
- R packages: dplyr, tidyr, data.table, ggplot2, readr, survival, R2WinBUGS or BRugs (or rjags if porting to JAGS)
- WinBUGS or OpenBUGS installed locally (or adapt scripts for JAGS)

To install common dependencies in R:

```r
install.packages(c("dplyr","tidyr","data.table","ggplot2","readr","survival"))
# For WinBUGS/OpenBUGS interface: install.packages("R2WinBUGS") or use BRugs from source
```


## Reproducing the analysis

Recommended workflow for reproducibility:

1. Run `prep_study_data.R` to create `data/`.
2. Run `BUGS/script.R` to fit the Bayesian model and save posterior samples (use small chains for quick checks and larger chains for final analysis).
3. Run `main-ce-analysis.R` to perform the Markov simulations and compute costs/QALYs.
4. Run plotting scripts (e.g. `pop_counts_plot.R`) to create figures and summary tables in `output/`.

Tips:
- Use a reproducible seed (set.seed()) for simulations.
- Keep a record of BUGS settings (number of iterations, burn-in, thinning) used for the final analysis.


## Outputs

Analysis scripts save outputs (tables, plots) into `output/`. Typical outputs include:

- Cost and QALY summaries by strategy / risk group
- Incremental cost-effectiveness ratios (ICERs)
- Cost-effectiveness acceptability curves (CEACs)
- Plots of population counts and state occupancy over time
